# 🎟️ EventMaster - Система за управление на събития

**EventMaster** е модерна уеб платформа, изградена с **ASP.NET Core MVC**, която позволява на потребителите да откриват, разглеждат и купуват билети за различни събития (концерти, театри, фестивали). 

Проектът включва както потребителска част, така и защитен Административен панел за управление на съдържанието.

## 🚀 Ключови функционалности

### 👤 Потребителска част (Public Area)
* **Разглеждане и търсене**: Потребителите могат да търсят събития по ключови думи.
* **Детайли за събитие**: Пълна информация, включваща дата, място и описание.
* **Покупка на билети**: Бърза система за запазване на билети.
* **Контактна форма**: Възможност за изпращане на запитвания към администраторите.
* **Модерен UI/UX**: Изчистен и респонсив дизайн, изграден с Bootstrap 5 и Bootstrap Icons.

### 🛡️ Административен панел (Admin Area)
* **Управление на събития (CRUD)**: Добавяне, редактиране и изтриване на събития.
* **Управление на категории**: Организиране на събитията по видове (напр. Музика, Театър).
* **Преглед на съобщения**: Четене и изтриване на запитвания от потребители, изпратени чрез контактната форма.

## 🛠️ Използвани технологии

* **Framework:** ASP.NET Core 8.0 MVC (или 6.0)
* **Database:** Microsoft SQL Server & Entity Framework Core
* **Frontend:** HTML5, CSS3, Bootstrap 5, Razor Pages
* **Testing:** xUnit, Moq, InMemoryDatabase (над 65% покритие на кода)
* **Authentication:** ASP.NET Core Identity (Roles: Admin, User)

## 🧪 Unit Тестове (Code Coverage)
Проектът е покрит със задълбочени Unit тестове, гарантиращи правилната работа на бизнес логиката. Тествани са:
* Функционалностите за търсене на събития.
* Защитата и валидацията на формите.
* Административните контроли (Events, Categories, Messages).
* Обработката на грешки (Error handling).
