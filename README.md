**EventMaster** е модерно уеб приложение, създадено за лесно организиране, откриване и управление на събития от всякакъв вид – от рок концерти и театрални постановки до мащабни гейминг турнири.

### 👤 За Потребители:
* **Разглеждане на събития:** Търсене и филтриране на актуални събития по категории.
* **Детайлна информация:** Подробно описание, дата, час и локация (Venue) за всяко събитие.
* **Система за автентикация:** Сигурна регистрация и вход чрез **ASP.NET Core Identity**.
* **Адаптивен дизайн:** Пълна поддръжка на мобилни устройства и таблети.

### 🔐 За Администратори (Admin Panel):
* **Управление на събития:** Пълен CRUD (създаване, редактиране, изтриване) на събития.
* **Категории и Локации:** Управление на списъците с категории и места за провеждане.
* **Контрол на достъпа:** Само потребители с роля `Administrator` имат достъп до управленските функции.

---

## 🛠 Технологичен Стек

* **Backend:** ASP.NET Core 8.0 (MVC)
* **Database:** MS SQL Server
* **ORM:** Entity Framework Core
* **Identity:** ASP.NET Core Identity за роли и сигурност
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Deployment (Хостинг):** * **Web App:** Microsoft Azure (Germany West Central)
    * **Database:** SmarterASP.net
